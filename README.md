# CTM_Assignment_2025-26
Hello CTM Applicants!!

This Repository contains the Design Assignment and challenges of CTM selection for 2025-26. Each of them is in a seperate directory.

## General Guidelines
For each challenge (unless otherwise stated). Your goal is to find a "flag" from the files provided, look at the readme file to get yourself started. You will also be required to provide a write-up for each challenge.

For challenges that you solve it will be sufficient to explain the method by which you solve them and provide any scripts/payloads you may have written to solve the challenge.

For challenges you are unable to solve your writeup should contain **all** the approaches you tried. Selection is not based on just finding the correct flag, we also want to see your thinking hence the writeups are crucial.

## Submission instructions
Here is the [submission form](https://forms.gle/fDLmV2TLVm7mZJC39)

To submit create a google drive folder with appropriate sub-directories for each of the challenges. If there's a flag have it in a file called flag.txt also include a writeup in the directory. You will have to submit a link with the drive folder. (Don't forget to set visibility to anyone with link!)

To be considered for the position of CTM it is **mandatory** to submit the design assignment and writeups for each challenge. (Even if you are unable to solve the challenge).



Flag format: CSeC{}
Here are some [resources to get you started](https://cseciitb.github.io/resources/)
